# optiprompt

Автоматическая оптимизация промптов для LLM с помощью локальной [Ollama](https://ollama.com).

`optiprompt` принимает шаблон промпта (с переменными вида `{{ variable }}`) и файл с тестовыми данными, а затем итеративно улучшает шаблон, генерируя гипотезы с помощью LLM и проверяя их на ваших примерах.

## Возможности

- 🧠 **Генерация гипотез** — LLM предлагает конкретные улучшения для вашего промпта.
- 🔄 **Итеративная оптимизация** — каждый цикл: гипотеза → новый шаблон → оценка → выбор лучшего.
- 📊 **Настраиваемая оценка** — `exact-match`, `contains` или `llm-judge` (оценка моделью).
- 📁 **Локальное хранилище** — все результаты сохраняются в читаемые Markdown‑файлы.
- 🧩 **Гибкие входные данные** — JSON или CSV с переменными для подстановки.
- 🐍 **Только стандартная библиотека** — никаких внешних зависимостей, кроме самой Ollama.
- 🖥️ **Полностью локально** — данные не покидают ваш компьютер.

## Требования

- Python 3.10 или выше
- [Ollama](https://ollama.com) с загруженной моделью (по умолчанию `llama3.1`)

## Установка

1. Склонируйте репозиторий или просто скопируйте файл `main.py`.
2. Убедитесь, что Ollama запущена и нужная модель загружена:
   ```bash
   ollama serve
   ollama pull llama3.1   # или mistral, gemma2 и т.д.
   ```
3. Запускайте скрипт напрямую:
   ```bash
   python main.py --help
   ```

## Использование

Базовый синтаксис:
```bash
python main.py \
  --prompt "Переведи {{ text }} на французский" \
  --data-file test_data.json
```

Если шаблон хранится в файле:
```bash
python main.py \
  --prompt-file template.txt \
  --data-file test_data.csv \
  --max-iterations 10 \
  --criterion llm-judge
```

### Параметры командной строки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--prompt`, `-p` | Шаблон промпта (строка) | — |
| `--prompt-file`, `-f` | Файл с шаблоном промпта | — |
| `--data-file`, `-d` | JSON/CSV файл с тестовыми данными | обязательно |
| `--max-iterations`, `-m` | Максимальное число итераций | 5 |
| `--hypotheses-count`, `-n` | Количество гипотез за итерацию | 3 |
| `--patience` | Остановиться после N итераций без улучшений | 2 |
| `--criterion`, `-c` | Метод оценки: `exact-match`, `contains`, `llm-judge` | `contains` |
| `--model` | Название модели Ollama | `llama3.1` |
| `--ollama-url` | Адрес API Ollama | `http://localhost:11434` |
| `--session`, `-s` | Имя сессии для папки с результатами | дата‑время |

## Формат файла с данными

Файл должен содержать примеры входных данных и **эталонные ответы**.  
Для каждого примера создаётся объект (JSON) или строка (CSV) с переменными и полем `reference` (или `expected`).  
Остальные поля — переменные, которые будут подставлены в шаблон.

### JSON
```json
[
  {
    "text": "Hello",
    "reference": "Bonjour"
  },
  {
    "text": "Goodbye",
    "context": "formal",
    "reference": "Au revoir"
  }
]
```

### CSV
```csv
text,context,reference
Hello,,Bonjour
Goodbye,formal,"Au revoir"
```

**Важно:** имена переменных в файле должны совпадать с именами в шаблоне (`{{ variable }}`).  
Если переменная из файла не используется в шаблоне, будет выведено предупреждение.

## Как это работает

1. **Шаблон** — вы даёте промпт с плейсхолдерами, например:  
   `"Переведи {{ text }} на {{ target_lang }}, сохраняя стиль {{ style }}."`
2. **Данные** — файл с конкретными значениями и ожидаемыми ответами.
3. **Оценка** — система подставляет значения, отправляет промпт в Ollama и сравнивает ответ с эталоном по выбранному критерию.
4. **Гипотезы** — LLM генерирует несколько идей по улучшению шаблона (не затрагивая имена переменных).
5. **Тестирование** — для каждой гипотезы создаётся новый вариант шаблона, который оценивается на всех тестовых примерах.
6. **Эволюция** — если какой‑то вариант показал лучший средний балл, он становится новым эталоном, и цикл повторяется.
7. **Результат** — после остановки вы получаете лучший шаблон и полный отчёт.

## Пример работы

```bash
$ python main.py --prompt "Summarize {{ text }}" --data-file data.json --max-iterations 3

============================================================
OPTIPROMPT — Оптимизация шаблона промпта
============================================================
...
Эталонная оценка: 0.650

ИТЕРАЦИЯ 1/3
  Гипотеза 1/3: Добавить указание максимальной длины...
    Оценка: 0.720 (эталон: 0.650) [+] УЛУЧШЕНИЕ!
  Гипотеза 2/3: Уточнить стиль резюме...
    Оценка: 0.680 (эталон: 0.650) [+] УЛУЧШЕНИЕ!
  ...
  >>> Новый эталон! Оценка: 0.720
```

## Результаты

Все результаты сохраняются в папку `~/.optiprompt/<имя_сессии>/`:

```
~/.optiprompt/20260101_120000/
├── baseline_evaluation.md    # оценка исходного шаблона
├── iter01_hyp1.md            # итерация 1, гипотеза 1
├── iter01_hyp2.md            # ...
├── best_prompt.txt           # лучший шаблон (обновляется)
└── final_report.md           # итоговый отчёт
```

Каждый файл – это Markdown с подробным описанием гипотезы, изменённого шаблона и таблицей результатов тестирования.
