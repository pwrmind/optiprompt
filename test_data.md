разработка системных требований консольного приложения (cli) автоматизированной отладки и тестирования промптов для llm: выдвижение гипотезы, проверка, сравнение результатов, взять тот, что дал лучшие результаты. Новый промпт подается на вход. Система выдвигает ряд гипотез (при помощи llm) по улучшению промпта. Для каждой гипотезы создается новый промпт, запускается. Результат сравнивается с эталонным. Если результат лучше - он становится новым эталоном.
